# API 原生 Agent 重构说明

状态：已完成本地启动、前端构建与基础接口验证；未进行真实模型调用或完整回归。日期：2026-10-26。

## 已实现的范围

- 普通问答与 PPT 制作共用 `backend/agent/runtime/loop.py`；API 原生调用标识与响应历史保留，不再重建一套虚构调用序号。
- 普通问答只开放 `search_regulations`，模型直接文本原样进入交付；移除首轮直答白名单、程序合成检索、全局实体逐字绑定、强制事实成文与正文修复。
- 新基础提示词为 `backend/prompts/api-agent.txt`，配置与运行配置已指向该文件。当前 API 提供方、模型及生成参数未切换。
- 移除 writer profile 和 composition 任务配置，以及独立 calculate、request_input、create_ppt 的模型工具入口。课程等其他业务工具不再注册。
- 旧主图的成文、补问、实体校验、计算预检、交接和工具执行模块已删除；检索内部的资料与政策记录处理不在本轮重做范围。
- 新 B/C/D 为 read_file、write_file、edit_file、execute_python，只在制作任务提供。文件访问限定任务目录与已安装 Skill 只读资源；来源、确认记录、检查和导出目录不允许模型直接改写。
- Python 代码采用受限语言与明确的文件能力，在独立进程运行；仅开放 math/json/csv/statistics 等现有标准处理能力。任意系统导入、网络和后台配置不可访问。Windows 复用已声明的 pywin32 设置进程内存限制，代码结果通过相同 C 权限检查后写入。
- 已安装脚本通过现有 PPT Master 执行器运行，不新增 shell 工具；执行进程不继承 API/数据库密钥。
- PPT Master 仍位于 `third_party/ppt-master/skills/ppt-master`，原版文件未修改。启动时提供目录元数据，由模型通过 B 按需读取 Skill；不再预加载三份上游流程或单独维护 PPT 专属模型循环。
- 真实用户确认继续通过现有网页与任务接口保存。自然语言提问结束当前模型回合；后续用户答复继续原任务，不新增 G。
- PPT 仍以实际导出文件登记、预览、确认和下载；实际文件与用户权限不由模型的“已完成”文字决定。
- 本地 Qdrant 客户端设置跨线程使用选项，以承接请求工作线程；未重建集合、重算向量或修改 BM25。

## 明确的使用边界

- 普通聊天不创建制作任务。模型会引导用户进入现有侧边栏演示文稿工作区，B/C/D 在该制作任务内启用。
- 未完成的旧 PPT 模型执行协议不能直接混入新工具历史，需要重新生成；已有成品仍保留查看和下载服务。
- 页级替换和拆分需要在现有工作区选择页面，不再调用另一轮 JSON 规划器猜测目标页；追加可以不选。
- 外挂 Skill 仍需宿主提供文件、脚本、材料、确认与产物服务；本次没有建设插件市场、自动安装或其他 Agent。
- 普通计算交给模型，不再强制调用计算工具或先取得计算记录。已有用户显式创建的 PPT 数据分析记录仍可用于图表，与独立成绩换算工具不同。
- 旧提示词、历史审计记录和离线训练资料保留为历史资料，不作为当前主流程指令。
- 前端类型检查和构建已在后续本地启动授权中完成，`frontend/dist` 已更新。

## 后续通用 PPT 与问答依据边界修改（待验证、待启用）

用户认可通用 PPT 改进方案，并要求先收紧问答无检索依据时的回答范围。本轮已修改源码：

- 系统提示词明确：无可用依据时暂时无法据此回答；部分依据只答已支持部分；工具故障不冒充没有资料；普通交流仍可直接回答。没有恢复固定成文 JSON 或关键词路由。
- 检索精排的 TimeoutError 向上传播，不再被普通失败分支吞掉后继续回退。
- 新 PPT 任务默认 general；仅 campus 模式提供校园检索。旧 public 值保留可读，按通用模式执行，不伪称具有联网能力。provided_only 继续要求真实材料。
- 工作区支持主题直接开始、可选受众/页数/资料、现有 Skill 的三种视觉参考及自由风格描述、可编辑方案、真实步骤反馈和页级修改快捷意见。
- 图片上传支持 PNG/JPEG/WebP，在当前任务内保存并归一化为 PNG，供 Skill 排版使用；不声称已识别图片内容。不新增联网搜索、自动找图或生图。
- 任务文件读写在进程内协调，Windows 短暂文件占用只有限重试；同任务制作请求互斥，启动时将遗留 generating 状态恢复为 paused。目录读取可返回真实文件名，不存在文件返回同目录提示；整轮工具均失败时暂停自动续做。
- 原版 Skill、真实确认、来源校验、实际导出和未选页面保护继续保留。

本轮未运行语法、导入、测试、类型检查、构建、浏览器验收或真实模型调用；未重启服务。此前启动验证结果不代表本轮修改已通过验证。实施范围及待申请检查见 `docs/superpowers/plans/2026-10-26-presentation-workspace.md`。
