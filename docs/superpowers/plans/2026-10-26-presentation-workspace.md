# 通用 PPT 工作区与问答依据边界实施计划

> 本计划按用户已批准的方案在当前会话实施。修改落地时遵守“先申请测试”；用户随后批准最小离线验证、构建和更新本地服务。不调用付费 API，不新增代理或提交整库。

**Goal:** 问答无检索依据时停止猜测；PPT 支持任意主题，材料可选、校园检索可选，沿用外挂 PPT Master。

**Architecture:** 问答通过精简系统提示词明确证据边界，不恢复固定成文 JSON。PPT 继续使用现有任务、通用文件工具和原版 Skill，修复实际执行故障，并改善简报、风格参考、进度和页级修改。

**Tech Stack:** Python / FastAPI / Pydantic / Vue 3 / TypeScript / 已安装 PPT Master。

**Spec:** 当前会话用户认可的通用 PPT 改进方案，以及本轮追加的“没有检索到就暂时无法回答”。

## Global Constraints

- 普通闲聊不强制检索；无依据不编造学校事实，工具故障不映射成无资料。
- 原版 Skill 文件保持原样；保留任务隔离、真实用户确认、来源真实性和实际导出校验。
- 不添加联网搜索、自动找图、生图、模型切换或新的成文契约。
- 验证仅限用户随后批准的语法/导入、模拟模型与临时资料、前端检查和构建、本地服务更新；不执行真实模型推理或服务器操作。

## Review Focus

- 无检索结果、部分依据、工具故障与普通闲聊的回答边界不同。
- 无材料的主题创作可开始；仅材料模式仍需真实材料；旧策略值仍可读取，旧 public 不再开放校园检索。
- 通用模式不得调用校园检索；具体数字与政策不由模型杜撰。
- Windows 文件短暂占用、重复制作请求及重启中断不能导致无限自动续跑。
- 图片只进入当前用户任务；风格参考不是成品预览，未选页面不改写。
