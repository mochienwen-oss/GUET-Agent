# API Composition Baseline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立显式可复现、经过分层及真实入口验收的API成文候选，为后续校园业务开发提供有支持范围的基线。

**Architecture:** 保留三层漏斗、任务边界、检索、计算、来源与FinalAnswer。在现有最终成文入口选择冻结writer-focus-20261024-1，不通过实验monkeypatch运行；默认保持原有配置。仅有证据的缺陷才进入实现，真实新题外发另按具体范围授权。

**Tech Stack:** Python/FastAPI/LangGraph，既有DeepSeek Responses适配器、pytest、SQLite本地交付验证。

**Spec:** 主会话已收到用户经侧会话交接并明确授权执行的五阶段顺序；本记录固定下列范围，不扩大为全Agent模型替换。

## Global Constraints

- 本地第一阶段已授权，不切换会话模型、不新建任务、不使用子代理。
- 现有枚举修复97项回归及76份草稿回放为既有证据，不冒充新增语义正确率。
- 不继续微调9B，不改候选提示、召回、schema或生成策略；正式默认不先于验收切换。
- 新真实题集、外发内容、费用与服务器操作须依据有效具体授权；旧38/44题许可不覆盖20道新题。

## Review Focus

- 只改provider却仍走旧协议/提示：正常成文服务根据显式候选选择协议，38份实际发送消息与冻结请求比对。
- 规划误用API：规划原提示与提供方保持独立，HTTP模拟仅放行成文端点。
- 原始packet被减负改写：只整理发送视图，事实/来源版本留在原始packet及审计。
- 请求日志残留9B名称：同时记实际provider、请求模型、响应model、协议/提示/资料版本。
- 正确草稿交付不一致：真实聊天HTTP/SSE/SQLite路径验证；本地模拟与真实模型验收分别报告。
