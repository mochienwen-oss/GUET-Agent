# PPT 独立工作区 UI 实施计划

**目标：**执行已批准的界面设计；检索路由、模型调用和 PPT 制作逻辑不变。

**实现：**Vue 共享导航布局；校园问答保留原交互，PPT 使用独立页面和界面状态，复用现有材料、确认、修订、下载接口。唯一服务端新增是当前用户的只读任务摘要列表。

- [x] 导航：校园问答 / PPT 制作固定入口；历史默认最近 5 条，可收起和查看全部；移动端抽屉可关闭。
- [x] 工作区：任务列表、新建与恢复、四阶段进度、折叠材料、方案确认、缩略图选择与大图预览、选页修订及下载；聊天内仅显示工作区链接。
- [x] 验证：只读列表归属及摘要测试；前端构建；本地明确替身下检查导航、材料保存不创建聊天、两次确认、预览选页、修订、下载、移动端和深色显示。不调用付费模型。
- 同步取消：用户明确要求「暂且不同步」，仅完成本地修改。

完成条件：上述操作可用，旧聊天和任务可进入；修改范围不含检索触发机制、提示词、模型、PPT host 或生成逻辑。

验证结果：`test_materials_api.py` 4 项通过；`npm run build` 通过。实际路由配合明确的确认模型替身，浏览器完成上述交互；选页修订只验证发出的页面 ID 与反馈，返回值为测试替身；预览与下载使用已有真实 PPTX 和渲染图，不代表新增真实模型制作验收。390px 页面无横向溢出，浏览器页面错误为 0。结果和截图位于 `_work/phase8/ppt-workspace-ui-20261026/`，临时测试服务已关闭。
