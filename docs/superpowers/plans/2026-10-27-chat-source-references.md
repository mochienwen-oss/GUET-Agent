# 普通问答引用交互实施计划

目标：按本会话已确认方案，将答案中的真实引用连接到知识库原文，并展示发布年份、适用对象与材料范围。

边界：只修改普通问答和必要的文档元数据维护；不改变检索阈值、工具选择、三类检索终止回复或 PPT；不重建索引，不执行真实模型调用。

- [x] 保留检索来源的文档身份、片段身份、原文范围和表格行；在本轮工具结果中分配引用编号。
- [x] 随消息保存完整来源，在提交成功后将消息 ID 与来源通过 SSE 返回；兼容旧记录。
- [x] 增加按会话、消息及引用身份鉴权的原文读取；原文版本变化时保留历史摘录并停止精确定位。
- [x] 增加少量文档展示元数据及现有管理入口中的编辑能力；适用年级与发布年份分开。
- [x] 实现答案引用、悬停/聚焦摘录、来源汇总、右侧阅读面板及窄屏阅读，保持聊天滚动位置。
- [x] 人工阅读改动；语法、测试、类型检查和构建尚未运行，等待用户授权。

参考：WeKnora 的 ChatCitationFloat.vue、ChatReferenceSourceView.vue 与 referenceSources.ts；采用交互思路，不移入其框架或组件依赖。
