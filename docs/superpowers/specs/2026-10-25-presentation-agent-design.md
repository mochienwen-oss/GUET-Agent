# 材料驱动PPT Agent设计（用户已认可）

授权来自用户侧会话发送到本会话的具体方案：直接按预期效果实施，不重复询问同一设计。

目标：混合校园文档、文本和简单数据表生成有来源、口径明确、可预览的可编辑PPT，并完成一次只影响指定页面的修订。

职责：主Agent选择能力并传递会话/任务；create_presentation负责简报、材料、缺口、大纲、逐页内容和修订；材料适配器读取文档/公开网页/数据；制作执行器布局、图表、导出及预览；现有交付模块负责归属、确认和下载。保留现有create_ppt入口，不建设通用插件平台。

简报：目标、受众、预期理解/行动、页数、必须保留内容、材料范围、是否允许外部补充。只有影响结果的缺口才补问。简报在修订中保留。

材料包：每份记录稳定标识、标题、内容/表格、类型、定位、日期及适用范围。用户材料归任务，不进入公共知识库。历史助手文字不能独立作为事实依据；须回到原始文档或检索来源。首版文档支持UTF-8文本/Markdown、DOCX、可提取文字的PDF；数据支持CSV/XLSX。扫描PDF明确说明需可读文字，不伪造提取成功。

取材：已有材料充分直接制作，取消固定2—5次检索。仅给定材料、校园库补充、允许公开补充分别明确。关键事实缺口才查询；学校规定只采校园库或明确学校官方来源，其他公开来源记录URL/日期/对象。首版使用用户给出的公开URL定向读取，不宣称具备全网自主搜索。无关或未取得的依据保留缺口。

数据：代码计算count/sum/mean/share，保留字段、筛选、单位、分母。数值不由模型计算。缺少分母不能猜。柱状图/折线图、简单表格保持原生可编辑。专用CET计算器不改为通用分析器。

页面：稳定slide_id、purpose、正文/建议、来源、分析引用。修订须给当前revision和受影响页面；支持修改、替换、拆分、追加。未选页面的内容和稳定标识保持不变。只有整体目标/受众变化才重做整体。材料更新标记引用该材料的页面需更新；新草稿确认前不能下载旧确认版本，旧token不能下载新文件。

制作：先复用当前python-pptx证明内容链路，再以独立适配器评估hugohe3/ppt-master。安装完整所需包、固定版本、保留MIT声明，只允许后端构造命令，不向聊天模型开放shell。未执行上游完整工作流时不宣称集成其Quick/阶段恢复能力。导出和预览失败显式显示，不能把SVG截图称为最终PPT渲染。

验证：两份真实校园材料＋有公开出处的数据表制作样例；实际渲染每页、检查关键事实/适用对象/数据口径、原生图表表格；完成一次指定页面修改并比较其他页面。另用有背景缺口的任务验证公开材料补充。合成模型响应只验证工程契约，不冒充真实API效果。新增付费生成和服务器实际验收按具体范围授权。

范围：检索召回和原问答成文冻结，只有已复现且阻塞本功能的缺陷才修。无动画、旁白、视频、复杂图片重建、任意主题无限研究、完整多角色平台。
