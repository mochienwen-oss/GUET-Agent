## 4. 先修后修关系图：源 PDF 里**具备可恢复条件**

### 现状

- `_md/` 里 **63/63 全无** —— 连"先修"两个字都搜不到。**这不是解析漏了，是用户主动删的**（见 §3b）。

### 源 PDF 里它是什么形态（实测 63 份）

| 项 | 结果 |
|---|---|
| 含 `八、课程先修后修关系图` 标题的 PDF | **63 / 63** |
| 该节以**矢量绘图**呈现（`page.get_drawings()` > 0） | **53 / 63** |
| 该节**无矢量对象**（须靠位图） | **10 / 63** |
| 该页含位图对象 | 23 / 63 |

- 例（`计算机科学与技术` 第 8 页）：标题在文字层，该页 **0 张图片、30 个矢量对象**，
  正文紧邻 `（二）主要实践性教学环节：…毕业设计。` —— 说明**节点文字与连线都在矢量层**。
- 因此：**节点名可从文字层坐标取、边可从矢量线段取**，属"坐标恢复"而非"OCR 猜图"。

### 结论与边界

- **技术上具备可恢复条件**：53/63 可直接坐标抽取（文字 span 定位节点 + `get_drawings()` 取箭头）；
  另 10 份该页无矢量对象，**位图那部分只能 OCR**。
- ⚠️ **但"可恢复"不等于"该恢复"** —— md 里没有它是**用户主动删的**（§3b）。
  本审计只给技术可行性，**是否恢复、恢复到哪一层，待用户裁决**。
- **红线**（设计 §7.2）：**OCR 堆叠文字不得入库**。若某份只能得到堆叠文字 → 该份应
  **标记为不可用**，而不是硬抽成假关系边。
- **不得从 `_md` 恢复** —— 那里本来就没有；也不能靠"课程名里含某词"猜先修关系。

## 5. `low_confidence` 为什么失真

**现行口径**（`build_plan_db.py:512`）：

```python
"low_confidence": any(w["code"] in ("header_exploded", "row_rejected", "cover_missing") for w in warns)
```

实测：**63 份里只有 1 份被标**（`密码科学与技术`）。而同期实打实的问题是：
**63/63 缺整节、12 份丢课程、8 份学分明细不全。**

三个失真来源：

1. **集合太窄**。判据只认 3 个 code，而解析器实际产出的还有
   `syllabus_name_unresolved`(55)、`cover_credits_missing`(4)、`credit_corrected`(1)、
   `anchored_empty`、`module_credits_missing`、`basic_missing` —— **都不在集合里**。
   例：`cover_credits_missing` 与 `cover_missing` 只差一个词，却一进一出。
2. **它量的不是"输出对不对"，而是"有没有撞上特定 warning"**。
   F1（21 行因冒号被丢）**根本不产生任何 warning** —— 丢弃是 `_is_data_row` 返回 `False`
   的**正常路径**，连 `row_rejected` 都不会报（`row_rejected` 只统计通过 `_is_data_row` 之后又被
   学分/同名判据剔掉的行）。**最大的缺陷恰好是最安静的。**
3. **级联会放大也会掩盖**。`row_rejected` 一旦触发就把整份标低；而真正大面积的问题（缺整节）
   没有任何 warning 可触发。于是出现：**1 份被标（它确有丢行），11 份该被标却没被标。**

> 结论：`low_confidence` 当前**不能当作"这份解析得对不对"的代理指标**。
> 要用它，得改成"按**输出**对账"（丢行数 / 学分对账 / 矩阵匹配率），而不是"有没有触发某几个 warning"。
