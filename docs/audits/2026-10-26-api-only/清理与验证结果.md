日期：2026-10-26。用户已授权审计并清理 Qwen 专属运行链路。**付费 API 调用 0；未连接或部署服务器；未启动可供真实问答的完整常驻服务。**

## 实际改动

- `backend/llm/llm_client.py`：规划、流式、成文、标题和相关性评估只调用统一 API；删除本地生成请求及旧采样注入。
- `llm_api_config.py`：空配置不再返回历史模式，明确报错；缺配置/密钥仍不切换其他模型。
- `final_answer_profile.py`：业务正文协议与 API 供应商/模型解耦，删除旧固定 DeepSeek 配对要求；不删除来源绑定和业务协议校验。
- `create_ppt/scripts/generate.py`：移除本地模型备选调用；PPT Master host 与交付、材料和版本约束保持。
- `runtime/model.py`：仅保留 API 规划与 request_input，对话动作不再取决于本地/远程模式分支。
- `tool_execution.py`：删除旧每轮前 3 个调用截断；去重、总调用、步骤、重试及时限预算保留，超预算调用仍给出未执行观察。
- `core/config.py`、lifespan、runtime_identity：移除旧生成字段和权重/模型探测、训练预算启动接线；保留资料身份和知识库核验。
- `scripts/runtime_service.py`、运行 profile、Compose 和配置示例：不再声明或启动 vLLM，移除生成权重和旧生成环境字段。
- 新增 `scripts/local_api.py`：正常 main:app 的跨平台本地入口，默认 CPU 检索、回环地址，不执行付费启动探测。
- 删除 `backend/llm/deepseek_client.py`、`deploy/vllm-server.service`、`deploy/api-writer.env.example`、`scripts/download_base.py`、`scripts/quantize_gptq.py`。旧 Qwen 前缀/单独成文测试改为 API 协议测试；其他受影响断言与测试输入随接口迁移。

没有修改真实 backend/.env、密钥、知识库内容、实体目录产物、Prompt 的业务内容或服务器。历史训练数据、原始验收结果及离线训练工具保留；它们不是当前服务的本地生成回退。当前服务生成调用入口不再引用 Qwen/vLLM 配置或单独 DeepSeek 成文通道。

3. 实际知识库源核验未修复；没有重建索引、目录指纹或变更来源门槛。
4. 没有新的真实 API A/B/C 质量指标，未评估当前模型对所有历史故障是否仍有同类错误。后续实验必须另行确认费用与资料范围。
